# Minesweeper Clone - GUI (Java)

This is a graphical user interface (GUI) implementation of the classic Minesweeper game, built using Java. It features a grid of cells, with hidden mines that the player must avoid. The objective is to uncover all non-mine cells without detonating any mines.

## Features

- **GUI-based Interface**: A clean and user-friendly interface built using Java Swing.
- **Customizable Grid Size**: Players can choose different grid sizes.
- **Mine Placement**: Mines are randomly placed on the grid.
- **Timer**: Tracks the time taken to complete the game.
- **Win and Loss Conditions**: The game ends when all non-mine cells are uncovered (win) or when a mine is clicked (loss).
- **Cell Marking**: Mark cells that you suspect have mines.
